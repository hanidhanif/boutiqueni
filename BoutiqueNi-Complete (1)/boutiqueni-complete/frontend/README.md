# BoutiqueNi — Frontend (GitHub Pages)

## Struktur
```
boutiqueni-frontend/
├── index.html
├── style.css
├── script.js
├── config.js          ← HANYA isi API_URL di sini
├── assets/
│   ├── hero-muslimah.jpg
│   ├── about-muslimah.jpg
│   ├── gamis-ayleen.jpg
│   ├── gamis-hana.jpg
│   ├── set-khadijah.jpg
│   ├── set-naura.jpg
│   └── tunik-azzahra.jpg
└── README.md
```

## Setelah deploy Apps Script
1. Buka `config.js`
2. Ganti `API_URL` dengan Web App URL dari Apps Script
3. Commit & push ke repo GitHub Pages

## Admin
- Klik logo **BoutiqueNi** empat kali → login
- Password default: **Bismillaah** (disimpan di Script Properties, bukan di sini)

Lihat folder `boutiqueni-gs/` untuk backend + panduan setup lengkap.
